# Support

SPDX-License-Identifier: CC-BY-SA-4.0

SchweisOS is currently in the bootstrap engineering phase. It is not ready for
end-user installation on a primary machine.

## Where to Ask

- Use GitHub issues for reproducible project problems.
- Use feature requests for scoped improvements.
- Use ADR issues for architecture decisions or policy changes.

## Before Opening an Issue

- Check the documentation in [docs/](docs/).
- Include exact steps, expected behavior, and observed behavior.
- Include whether the issue affects documentation, packaging, ISO work,
  release engineering, security, or architecture.

## Unsupported Requests

The project does not currently provide:

- General Arch Linux support.
- Stable release support.
- Hardware-specific installation support.
- Support for unofficial forks or repackaged builds.

These boundaries may change after the first public alpha.
