# Design Decision Records

Version: 0.2
Status: Active
Date: 2026-07-29

Design Decision Records document durable SchweisOS user-experience decisions:
visual language, interaction flow, contributor-facing UX rationale, and the
tradeoffs behind how the system feels.

DDRs complement Architecture Decision Records. If a design decision also changes
system ownership, security boundaries, packaging, release engineering, or
maintenance policy, the technical architecture still needs an ADR.
