# SchweisOS Product Vision

Version: 1.0
Status: Accepted baseline
Date: 2026-07-24

## Vision

SchweisOS makes the power of Arch Linux accessible to more desktop users while staying close to upstream Arch. It combines gaming readiness, privacy, security, performance awareness, transparency, and ease of use in a maintainable Arch-based distribution.

## Target Users

- Users who want Arch's rolling base but prefer a guided installation and sane defaults.
- Linux gamers who want a practical setup without undocumented tuning.
- Privacy-conscious desktop users who want no default telemetry or forced account system.
- Curious users who still want terminal access and system control.
- Future contributors who need a clear technical foundation.

## Non-Goals

- Replacing Arch Linux.
- Writing a new package manager.
- Writing a new kernel.
- Forking large upstream packages without strong reason.
- Hiding Linux concepts completely from the user.

## Competitive Advantage

SchweisOS should compete through engineering clarity:

- Source-aware software installation.
- Gaming support based on measurable behavior.
- Conservative Arch alignment.
- Distrobox-based compatibility research for foreign Linux application ecosystems.
- Living documentation from the beginning.

Visual branding matters, but it is not the product's technical reason to exist.
